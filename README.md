# Food Buddy price list

`prices.json` is downloaded by the Food Buddy app (Panama) each time it opens.

- `updated`: date of the last refresh (YYYY-MM-DD).
- `prices`: USD per lb for weighed items, per quart for liquids, per piece or slice otherwise. Keys must match the ingredient names in the app.

Updated weekly from public supermarket listings in Panama. Values are estimates; the app lets people enter what they actually pay.
